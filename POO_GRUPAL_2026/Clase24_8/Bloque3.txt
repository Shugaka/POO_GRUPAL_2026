Ejercicio 3.4 · Escribí el código

Dado int[] numeros ya cargado, escribí el fragmento que resuelve cada punto:

1) Sumar todos los elementos e imprimir el total.

int suma = 0;
for (int i = 0; i < numeros.length; int++) {
    suma += numeros[i]
}
System.out.println(suma);

2) Encontrar e imprimir el valor máximo.

int mayor = 0;

for (int i = 0; i < numeros.length; int++) {
    if (numeros[i] > mayor) {
        mayor = numeros[i];
    }
}
System.out.println(mayor);

3) Contar cuántos elementos son mayores a 10.

int mayores10 = 0;

for (int i = 0; i < numeros.length; int++) {
    if (numeros[i] > 10) {
        mayores10 += 1;
    }
}
System.out.println(mayores10);
